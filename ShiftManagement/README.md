# 勤務表自動作成システム (Shift Management System)

介護施設・看護施設（ライフステイむなかた）向けのWindowsデスクトップ勤務表自動作成業務アプリケーションです。  
Google OR-Tools (CP-SAT) 数理最適化ソルバーを搭載し、複雑な業務制約を満たした最適な勤務表を3案自動生成します。

---

## 主な機能

1. **数理最適化による3案自動生成 (OR-Tools CP-SAT)**
   - **案1（総合評価最大化案）**: 全体の希望達成度と勤務バランスを最大化した標準解
   - **案2（夜勤配置最多様化案）**: 案1とは異なる夜勤配置パターンを探索した多様化解
   - **案3（勤務負担均等化案）**: 夜勤回数・勤務負担指数の公平性を最重視した平準化解
   - **解なし（INFEASIBLE）時の競合診断・緩和提案**: 制約が厳しすぎて解が存在しない場合、競合要因と具体的な緩和アクションを自動提示

2. **独立バリデーターによる厳格な制約チェック**
   - ソルバーから完全に独立した `ShiftValidator` により、Hard制約（違反不可）およびSoft制約（要望）を常時客観評価
   - **Hard制約**:
     - HC-01: 1日1勤務の原則
     - HC-02: 夜勤シーケンス（夜勤入り `2－`/`3－` → 夜勤明け `－` → 休み `ヤ`/`有`）
     - HC-03: 各日必要人数の充足（2早, 2オ, 2－, 3早, 3オ, 3－, 日）
     - HC-04: 最大連続勤務日数（5日以内）
     - HC-05: 月間最低休日数（9日以上）
     - HC-06: 日曜日最低1回休日
     - HC-07〜13: 職員個別制約（松浦洋子: 夜勤不可, 上松伸次: 2階専従, 三吉孝明: 3階早出/遅出/休みのみ, 長岡妙子: 2階夜勤専従・希望日のみ）
     - HC-14/15: 勤務不可日・絶対希望休
   - **Soft制約**:
     - SC-01/02: 希望休・希望勤務
     - SC-04: 松浦洋子の日勤優先
     - SC-06: 夜勤回数目標（月4回目標等）
     - SC-07/08: 夜勤回数および勤務負担度の公平性
     - SC-09: 三吉孝明の早出・遅出ブロック混在抑制

3. **直感的なWPFデスクトップUI**
   - **ダッシュボード**: 対象月ステータス、職員数、最新採用案スコアのサマリー
   - **職員管理**: 職員属性、資格、固定制約の編集・無効化
   - **勤務希望入力カレンダー**: カレンダーセルからワンクリックで希望休・勤務不可等を直感入力
   - **自動生成画面**: 進捗バー表示、3案プレビュー、解なし診断アラート
   - **勤務表詳細・手動修正**: マトリクスグリッド表示、ダブルクリックでの勤務変更パレット、Undo/Redo、リアルタイム制約違反警告
   - **3案比較画面**: 各案の指標（スコア、違反数、希望達成率、夜勤分散）の横並び比較と正式採用決定
   - **システム設定**: 施設パラメータ設定、SQLiteデータベースのバックアップ作成・復元

4. **Excel入出力 (ClosedXML)**
   - 既存の勤務表フォーマット（`勤務表３月サンプル.xlsx`）のレイアウト・配色・集計欄を忠実再現
   - **シート構成**:
     1. `勤務表`: テンプレート準拠のメイン勤務表（集計列・カラーリング・日勤青字対応）
     2. `個人別評価`: 職員別の勤務回数内訳、勤務負担度、希望達成度一覧
     3. `条件一覧`: 適用された施設制約・職員個別条件一覧
     4. `日別集計`: 日付別の必要人数と配置人数の過不足集計

5. **信頼性と保守性**
   - **データ永続化**: SQLite (Entity Framework Core)
   - **ロギング**: Serilog による日別ローテーションログ (`%LocalAppData%\ShiftManagement\Logs`)
   - **自動保存・バックアップ**: 編集内容のバックグラウンド自動保存、手動/定期バックアップおよびワンクリック復元

## ソリューション構成

```
ShiftManagement/
├── ShiftManagement.sln
├── src/
│   ├── ShiftManagement.Core/          # ドメインモデル・インターフェース・制約定義
│   ├── ShiftManagement.Data/          # SQLite EF Core DbContext・リポジトリ・初期データ投入
│   ├── ShiftManagement.Optimization/  # Google OR-Tools CP-SAT ソルバー・3案生成・競合診断
│   ├── ShiftManagement.Validation/    # 独立バリデーター・統計評価エンジン
│   ├── ShiftManagement.Excel/         # ClosedXML Excel出力・テンプレート反映
│   ├── ShiftManagement.Infrastructure/# Serilogログ・自動保存・バックアップ・Undo/Redo
│   └── ShiftManagement.App/           # WPF デスクトップ UI (MVVM, DIコンテナ)
└── tests/
    └── ShiftManagement.Tests.Unit/    # xUnit ユニットテスト (制約検証・評価計算)
```

## Windows環境での実行・ワンクリックショートカット作成

### 🌟 最も簡単な方法（ワンクリック設定）

1. zipファイルを解凍したフォルダを開きます。
2. **`デスクトップにショートカットを作成.bat`** をダブルクリックします。
3. 自動的にビルド・発行が行われ、Windowsのデスクトップに **「勤務表自動作成システム」** のショートカットアイコンが作成されます！
4. 以後は、**デスクトップのアイコンをダブルクリックするだけで即座にワンクリック起動** できます。

---

### コマンドラインからの実行・開発者向け

#### 必須要件
- Windows 10 / 11 (x64)
- [.NET 9 SDK](https://dotnet.microsoft.com/download/dotnet/9.0) (または Visual Studio 2022 最新版)

#### ビルド
```powershell
dotnet build ShiftManagement.sln -c Release
```

#### ユニットテスト実行
```powershell
dotnet test tests/ShiftManagement.Tests.Unit/ShiftManagement.Tests.Unit.csproj
```

#### コマンドライン直接起動
```powershell
dotnet run --project src/ShiftManagement.App/ShiftManagement.App.csproj
```
またはフォルダ内の **`アプリを起動.bat`** をダブルクリックしてください。

※初回起動時に SQLite データベース (`shifts.db`) が自動作成され、仕様書に準拠した14名の職員マスタ・初期制約が自動的に投入されます。事前のデータベース設定等は一切不要です。
